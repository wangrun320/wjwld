# 王金武乱斗 V27：角色战斗系统重做

## 本版主要变化

- 玩家炸弹按钮、按键和投掷炸弹逻辑已删除。
- 每个角色现在有：1 套专属普攻、2 个带独立冷却的小技能、1 个带长冷却的大招。
- 普攻增加角色独立的攻击间隔与后摇。按住普攻也必须等待本角色攻击节奏，不能无间隔连发。
- 普攻类型已区分：近战扇形挥击、双发速射、重锤近战、治疗光弹、三枚手里剑、穿透激光、范围奥术弹。
- 技能按钮会显示冷却剩余时间；冷却期间不可再次触发。
- 传说装备的主动效果改为大招共鸣加成，不再额外占一个移动端技能按钮。

## 操作

- 手机：左侧摇杆移动；右侧从左到右为普攻、小技能一、小技能二、大招。
- 电脑：WASD 移动、鼠标瞄准、空格普攻、Q 小技能一、E 小技能二、R 大招。

## 技术范围和测试说明

- 角色技能重做已接入本项目的本地单人闯关战斗循环。
- 本项目 ZIP 不包含独立 WebSocket 联机服务器代码；客户端已发送新的 skill1、skill2、ultimate 输入字段，但联机服务器仍需同步实现这些字段，才能在多人房间中启用完整的新技能系统。
- 已检查 JavaScript 语法、HTML 结构、CSS 解析、技能按钮数量和角色技能配置。当前环境未能启动受控 Chromium 页面，因此未完成浏览器实机画面验证。
