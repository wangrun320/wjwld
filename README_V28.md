# 王金武乱斗 V28：角色动作、技能特效与技能图标升级

## 本版内容

- 新增 28 张独立技能图标：7 名角色分别拥有普攻、技能一、技能二、大招图标。
- 移动端四个战斗按钮现在显示对应角色的技能图标和名称。
- 普攻按钮显示攻击间隔/后摇剩余时间；两个小技能与大招分别显示独立 CD 数字和环形冷却遮罩。
- 冷却结束时按钮会短暂闪亮提示；技能 CD 中不能再次触发。
- 七名角色普攻的动作节奏、挥击形状和发射轨迹继续区分：王金武棍击、疾风侠双刃、铁壁王重锤、治愈师光球、忍者手里剑、机甲光束、法师星辉弹。
- 为各角色三个主动技能加入差异化画面特效：金色冲锋/棍阵/王冠冲击、风刃/龙卷、护盾/地裂/堡垒、治疗脉冲/光球/圣域、影袭/烟幕/影舞、电磁/能量护盾/轨道炮、奥术/冰环/陨星。
- 命中反馈包含敌人短暂闪白、受击抖动、击退、浮动伤害数字和弹体命中火花；玩家受击也会闪烁并显示冲击反馈。

## 操作

- 手机横屏：左侧摇杆移动，右侧依次为普攻、技能一、技能二、大招。
- 电脑：WASD 移动、鼠标瞄准、空格普攻、Q 技能一、E 技能二、R 大招。

## 测试说明

- 已检查 HTML 结构、JavaScript 语法、CSS 解析、28 张图标文件和运行时图标路径。
- 已确认技能 CD 状态由本地战斗循环刷新，技能按钮在冷却中禁用，普攻按钮保持按住操作可用。
- 本环境的 Chromium 截图启动超时，因此没有声称完成真实浏览器或手机上的视觉实机测试；仍建议部署前在 Android 横屏设备实际检查按钮尺寸和特效观感。
- 多人房间仍需要与独立 WebSocket 服务器同步技能与冷却协议；本版美术反馈和冷却 HUD 主要针对现有本地单人战斗。
