# 王金武乱斗 V26 · 三章 60 关单人战役

本版本基于 V25 大厅背景纯净整合版继续修改，保留原有大厅、账号/云存档、角色、装备、商城、好友、任务与横屏战斗操作。

## 单人战役

- 扩展为 60 关，分为 3 个章节，每章 20 关：
  - 1–20：青岚训练营
  - 21–40：赤焰荒野
  - 41–60：幽影古林
- 关卡选择界面改为章节切换，每章显示 20 个关卡节点。
- 按顺序解锁：必须通关当前关卡才能解锁下一关。
- 每 5 关安排一个首领/精英战；第 20、40、60 关分别为章节 Boss。
- 已通关关卡可以重玩；首次通关奖励、材料和宝箱只发放一次。
- 旧版存档若已经完成第 20 或第 40 关，会按历史通关星级自动解锁下一章节。

## 章节地图

- 青岚训练营：草地营地、河流桥梁、木制掩体。
- 赤焰荒野：矿车轨道、红色峡谷和熔岩危险区。
- 幽影古林：古代遗迹、水晶机关、毒雾和传送法阵。
- 每章包含 5 种布局模板；章节最终 Boss 关使用专属竞技场布局。
- 地图危险区域会造成伤害；幽影古林部分关卡的双传送门可以移动玩家。

## 敌人和难度成长

- 三章使用不同敌人阵容和颜色/外观组合，战斗中不再统一显示为普通玩家角色。
- 随关卡提高，敌人血量、攻击伤害、移动速度和攻击频率逐步提升。
- Boss 使用更高生命值，并会发射扇形弹幕。
