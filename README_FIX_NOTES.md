# 王金武乱斗 13.8 修复说明

本版本基于 13.7 修复，不新增大型玩法：
- 补齐云存档 REST 请求所需的 `authHeaders`，使用 Supabase anon key 与用户 access token。
- 横屏矮屏登录弹窗增加内部滚动与按钮触控区域，避免登录按钮被屏幕高度挤出可视区域。
- 单人模式普通移动与位移技能统一经过圆形碰撞检测，位移逐步推进并在墙体处停止，避免穿墙卡墙。
- 单人地图增加障碍数量，并避免障碍彼此过度重叠及遮挡出生点。
- 云存档失败提示改为显示实际错误，不再误导用户重复执行 SQL。

数据库结构未改动；不要重复执行 SQL，也不要删除现有玩家数据。
